# BALAJI S — Premium Portfolio

A responsive, animated personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the **Live Server** extension.

No Node.js installation is required for this version.

## Files

- `index.html` — portfolio content and sections
- `style.css` — premium responsive design and animations
- `script.js` — scroll reveals, progress bar, cursor glow, mobile menu and card tilt
- `assets/balaji-avatar.png` — generated portfolio avatar

## Customize

Update links, email, project links and content directly in `index.html`.
